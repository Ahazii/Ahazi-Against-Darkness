| Capture — ranger Clue reduction | p.102 / gap note p.62 | rejected | Gap analysis cited p.62 (Swashbuckler traits), not ranger capture. `clue_spends_table` captive_hideout costs 3 Clues (p.102) with no ranger discount; `classes.json` ranger has no hideout Clue rule. Marked `rejected_false_positive` in `mechanic_regression_map.json`. |
| Magic Challenge reaction | p.102 | wired 2026-06-13 | Reaction rows with `key: "magic_challenge"` now trigger a magical Save against the highest living foe level. No current bestiary row uses the key until source-specific table extraction assigns it. |
| Trade Information reaction | p.102 | wired 2026-06-13 | Sell information for 25gp per Clue held by heroes physically in the encounter without losing those Clues; buy 1 Clue for 100gp using gold carried by heroes physically in the encounter.
