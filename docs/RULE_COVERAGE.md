## Gap analysis: remaining party-split mechanics (EE PDF survey 2026-06-05)

The following party-splitting mechanics were identified in the EE rulebook but are **not yet implemented**:

| Mechanic | EE Location | Status | Notes |
| --- | --- | --- | --- |
| Capture — inventory strip | p.102 | wired 2026-06-13 | Captured heroes lose carried inventory and selected weapon defaults. The session stores stripped equipment and restores it when captives are rescued by combat, ransom, or angelic True Name rescue. Stripped gold remains treasure to loot. |
| Capture — ranger Clue reduction | p.62 | deferred | The gap analysis cited p.62 but the ranger's `classes.json` description does not mention a Clue cost reduction; no verbatim rule text was confirmed. Trivially implementable if confirmed (check for `class_id == "ranger"` in party and subtract 1 from `CLUES_FOR_SECRET_XP` in `_find_captive_hideout`). Deferred until the rule can be verified against the PDF. |
| Magic Challenge reaction | p.102 | wired 2026-06-13 | Reaction rows with `key: "magic_challenge"` now trigger a magical Save against the highest living foe level. Success resolves peacefully; failure starts combat with foes striking first and leaves a pending magical Save reroll where eligible. No current bestiary row uses the key until source-specific table extraction assigns it. |
| Trade Information reaction | p.102 | wired 2026-06-13 | Sell information for 25gp per Clue held by heroes physically in the encounter without losing those Clues; buy 1 Clue for 100gp using gold carried by heroes physically in the encounter. Split-party backend behavior and frontend button state are covered by regression tests. |
| Puzzle reaction | p.102 | starter | Wired for L-based Save; no table currently references it. |
| Druid forced split (Call of the Wild) | p.38 | wired 2026-06-13 | L10+ druid party-sheet action rolls d6 turns, detaches the druid, blocks actions/navigation/combat while away, decrements on dungeon-time actions, and allows rejoin when the countdown reaches 0. |
| Bard Song of Elidra full range | p.30 | wired 2026-06-13 | Once per adventure reaction bonus now uses same-or-adjacent connected map element range, including split-party/scout situations; distant detached groups are excluded. |
| Active group switching (detached movement) | p.105 | **wired 2026-06-12** | "Navigate" button on each detached group heading makes that group active for navigation. Detached scout rows also expose Navigate back / Wait here controls. The Exits panel and map door markers route movement through the active group's tile instead of the main party and the API forwards `detached_tile_id` for browser actions. Encounters at the destination queue as detached combat rounds. Dungeon exit blocked for detached groups. Active group auto-resets on reattach. Tests: `tests/test_active_group.py`, `tests/test_frontend_map_interactions.py`. |
