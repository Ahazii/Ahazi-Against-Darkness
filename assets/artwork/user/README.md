User Artwork Slots
==================

Place personal-use or licensed adventure, scene, item, monster, and portrait artwork in this folder tree. Replace the placeholder text files with PNG, JPG, GIF, or WebP images that use the dimensions in the filename.

Modern dashboard page artwork uses the sibling folder `DATA_DIR/assets/Application Artwork`, not this folder.

Keep copyrighted PDF crops local unless you have publication rights. The app can reference local artwork without committing the image itself.
