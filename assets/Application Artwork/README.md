# Application Artwork

These placeholder files are copied to `DATA_DIR/assets/Application Artwork` without overwriting local edits.

Replace a `*_REPLACE_WITH_GIF.txt` placeholder with a browser-supported image that uses the same basename and the `.gif` extension shown in the matching artwork registry entry. The modern dashboard serves `DATA_DIR/assets` first, then falls back to bundled assets.

Keep copyrighted PDF crops or publisher artwork local unless you have publication rights.
